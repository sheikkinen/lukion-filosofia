# Brief 003: FI2 Etiikka, accepted with minors

**Date:** 2026-11-22 **IDs:** brief 003

## What happened

Five researchers and a critic planned ten FI2 topics (order 11–20) with opened original passages: Herodotus on custom,
Hume's is and ought, Plato's *Euthyphro*, Aristotle on the mean, Bentham, Mill, Kant (quoted only up to the line
before his suicide example), Epicurus, Seneca, Locke and Wollstonecraft. The exam researcher returned nothing, so a
separate agent read seven sittings: FI2 is in every one. The content workflow wrote the topics; the judge rejected the
first round over task steps (15 of 30 over five), a missing safety flag on the Kant page and a few wrong statements.
A fix round ran beside the images (5 diagrams, 11 nano-banana scenes for $0.40, 5 Commons artworks); the judge
rejected once more over small items, which the producer and a last agent fixed. Accepted with minors.

## Traps

- **A researcher can come back empty.** Check every aspect returned before the critic's verdict is trusted.
- **Steps creep.** Writers padded tasks to 7–11 steps; the cap needs a counting check in the first round.
- **Data files grow past the cap quietly.** The materials list reached 605 lines and the two image manifests 501 and
  510; the engine reads only two manifest files, so comments were trimmed instead of splitting.
- **The judge can ask for the wrong form.** "Vaikuttaa arvioosi" takes the illative; the producer restored it.

## Heuristic

Run a script that counts task steps and file lines before the checkers, so they spend their time on substance.

**Seed:** Should the engine read any number of `data/images*.yaml` files, as its image tool already does?
