# Brief 004: FI3 Yhteiskuntafilosofia, accepted with minors

**Date:** 2026-11-22 **IDs:** brief 004

## What happened

The engine learned to read every `data/images-*.yaml` file (lukio-runko v0.3.0), because the two image manifests had
reached the 500-line cap. All five researchers returned this time. Ten FI3 topics (order 21–30) cover every FI3 code,
with 20 primary-text boxes in English, French, Italian, German, Latin and Greek, and five-slot ideology cards whose
critiques are word-counted against the view. The judge rejected three rounds: 25 items first (a Locke line translated
backwards, misquoted model answers, wrong edition years), 11 next (unmarked cuts, Mill's "should" lost, card balance),
then accepted. Images: 11 nano-banana scenes ($0.37), 5 diagrams, 3 Commons artworks in a new manifest file; the
Leviathan frontispiece (a sword) and a Machiavelli portrait of unclear source were dropped.

## Traps

- **The permission system stopped fixers from recording translation checks they had not made.** That guard is right:
  four boxes later found faulty had been marked checked by a redo round. From now on only the independent sources
  checker writes `checked_by`, and only for boxes it verifies.
- **Pushing a module's codes before its topics fails the live build,** which would also block other pushes (visual
  novel links). Module configuration stays local until the topics exist.
- **Quoting a sentence fragment needs a cut mark** (`– –`) in both the original and the translation.

## Heuristic

Let the checker, not the writer, record the check.

**Seed:** A small script could count each ideology card's slots and each task's steps before any agent reads the page.
